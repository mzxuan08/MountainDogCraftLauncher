# MDCL 架构与开发交接包

日期：2026-10-24。产品范围：Minecraft Java 版桌面启动器，支持 Windows 与 macOS。

本目录最初是架构设计和开发交接包；现在同时包含按任务书实现的 MDCL 工程。当前只完成 T00 桌面基线与 T01 实例存储核心，仍不是可用启动器。

**推荐采用 C# / .NET 10 LTS + Avalonia + MVVM。共享启动核心，分别实现 Windows 与 macOS 的系统适配，发布 win-x64、osx-arm64、osx-x64 三套产物。**

请按以下顺序阅读：

1. [架构设计](docs/MDCL-架构设计.md)：技术决策、模块职责、数据模型和关键流程。
2. [DSH 开发任务书](docs/DSH-开发任务书.md)：任务依赖、文件落点、阶段交付和验证方法。
3. [验收矩阵](docs/MDCL-验收矩阵.md)：功能、故障恢复和跨平台实测要求。
4. [参考依据与决策记录](docs/参考依据与决策记录.md)：从 PCL / HMCL 得到的经验、证据边界及来源。
5. [交给 DSH 的提示词](交给DSH的提示词.md)：可直接粘贴给 Dsh，并附上整个目录。
6. [具体架构设计](docs/MDCL-具体架构设计.md)：T00—T12 的模块、接口、事务、恢复、发布与测试基线。

设计重点是可靠启动、可恢复安装、账号保护和两平台一致的实例模型。首版完成原版游戏闭环；Fabric、Forge / NeoForge、整合包和自更新按阶段接入。

这些文档中的“必须”“不得”是 MDCL 的设计约束；性能数字是待验证的验收目标。文档核查不代表软件已经实现，也不代表已在 Mac 上运行。
