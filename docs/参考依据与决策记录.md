# 参考依据与决策记录

核查日期：2026-10-24。本设计阅读了两个仓库的结构与选定实现，并查看了官方技术文档和历史反馈，没有运行 PCL / HMCL 做对比测试。以下将已观察事实、历史报告与 MDCL 的设计判断分开。

上游默认分支会变动；开发开始时应记录所参考仓库的精确 commit。此交接包没有把未取得的 commit 编号补写为已固定基线。

## 经验如何转成架构

| 依据 | 可以确认或观察到的内容 | MDCL 采用的设计判断 |
| --- | --- | --- |
| PCL Java 模块与历史改进记录 | 当前选定源码会组合游戏与加载器的 Java 范围，还处理新版本元数据要求；历史记录反映搜索和优先级曾需要调整 | Java 约束先求交，再排序；解释淘汰原因；只扫描白名单目录 |
| PCL Minecraft 模块目录 | 启动、Java、下载、Modpack、崩溃分析有不同文件入口 | 按业务能力分工；进一步约束 UI 与启动核心的引用方向。这是 MDCL 决策，不表示已证实上游存在某种耦合缺陷 |
| HMCL Core / UI 与任务目录 | 独立核心含下载、账号、任务及启动实现 | 计划与执行分开，核心规则可离开 UI 测试 |
| HMCL DefaultDependencyManager | 依赖补全协调游戏资源、assets、libraries 等任务 | 用步骤依赖图编排安装，页面只订阅状态 |
| HMCL FileDownloadTask | 下载输入带候选来源与可选摘要校验，缓存与临时文件处理独立 | 校验失败绝不提交；MDCL 对摘要信任来源额外记录，避免把传输来源等同信任来源 |
| HMCL #1561 历史反馈 | 2022 年 UOS 用户报告中断 Java 下载后再下载可能校验失败；议题已关闭 | 将续传身份变化和坏残片纳入故障注入用例；不能据此声称当前 Windows / macOS 版仍有此问题 |
| HMCL MicrosoftService 与 #2979 | 认证涉及 Xbox、Minecraft 权益与 profile；历史 Mac 账号刷新反馈已关闭 | 登录分阶段建模，协议模拟与真实账号验证分开，不能把网页登录成功等同游戏会话可用 |
| 官方 Java 与 .NET 进程文档 | 参数列表、Java argfile 和环境注入各有语义 | 分别测试参数边界、长命令和环境清理，避免全部交给字符串拼接 |
| Avalonia 与 .NET 支持文档 | 跨平台框架支持与运行时支持不是同一张表 | 系统基线取交集，三个 RID 分别发布与验收 |
| macOS 部署规范 | .app、代码签名、公证和运行检查属于发布流程 | Mac 验收从 T00 进入，正式分发不能只交一份交叉编译目录 |

“事务安装、凭据保护、来源信任、归档边界”等是 MDCL 在该产品场景下的设计要求，并非对上游未实测漏洞的定性结论。未经复现、只有举报者说法或存在争议的安全清单不作为本设计的已确认缺陷来源。

## S01 PCL 与 HMCL 许可

- [PCL LICENCE](https://github.com/Meloong-Git/PCL/blob/main/LICENCE)：已直接读取。仓库文件列出分发有限许可的外部链接，并附合理使用指南；指南对轻度 / 重度使用区分命名、署名与其他要求，也明确自身不是法律文件。
- [HMCL README 的 License 部分](https://github.com/HMCL-dev/HMCL#license) 与 [LICENSE](https://github.com/HMCL-dev/HMCL/blob/main/LICENSE)：README 声明 GPLv3，并要求修改版合理区分名称或版本、保留版权声明。

本设计因此推荐独立实现。不能由“源码可见”推导为“可任意改名复制”，也不将仅采用抽象架构思想自动判定成源码二次开发。真正引入代码时逐项核对具体许可。

## S07 技术栈与系统支持

- [Avalonia Supported platforms](https://docs.avaloniaui.net/docs/supported-platforms)：核对 Windows / macOS、架构和支持层级。框架层面存在对较旧 OS 的支持，不等同所选 .NET 版本的正式支持。
- [.NET 支持政策](https://dotnet.microsoft.com/en-us/platform/support/policy)：确认 .NET 10 为当前受支持 LTS。本方案锁定主版本 10，具体 SDK 和包补丁由 T00 核实并固定。
- [.NET 10 Supported OS](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md)：核对系统基线；设计当日文档列出的受支持 macOS 包含 15、26、27，Windows 支持具体系统版本与生命周期。MDCL 不因 UI 框架仍列 macOS 14 就默认承诺该平台。
- [WPF 概述](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/overview/)：WPF 仅运行于 Windows，不适用于本项目的双平台界面要求。

## S09 进程参数与 Java 参数文件

- [ProcessStartInfo.ArgumentList](https://learn.microsoft.com/en-us/dotnet/api/system.diagnostics.processstartinfo.argumentlist)：逐项传参及转义行为；不应据此认为所有外部输入都已安全或命令长度不受限。
- [Java 21 java 命令](https://docs.oracle.com/en/java/javase/21/docs/specs/man/java.html)：参数文件、环境变量和启动参数语义。此文档用于描述已采用的现代 Java 参数机制，不用来推断 Java 8 也支持相同能力。
- [Win32 重定向子进程输入输出](https://learn.microsoft.com/en-us/windows/win32/procthread/creating-a-child-process-with-redirected-input-and-output)：进程管道与句柄生命周期的参考。

## S10 凭据与 macOS 发布

- [ProtectedData](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.protecteddata)：Windows DPAPI 与 CurrentUser 范围的一般依据；实现时依赖稳定版包。
- [Apple Keychain services](https://developer.apple.com/documentation/security/keychain-services)：Apple 官方入口；本次页面返回需要 JavaScript，未取得完整 API 正文。Keychain adapter 的具体 API 和错误码由 T05 在 Mac 上验证。
- [Avalonia macOS 部署](https://docs.avaloniaui.net/docs/deployment/macos/)：已读取 .app 结构、apphost、执行权限、签名与公证流程。正式分发行为必须在 Mac 上验证。

## 已作出的决策与后续验证

| 决策 | 现在采用 | 开发阶段必须验证 |
| --- | --- | --- |
| 双平台 UI | Avalonia + .NET 10，替代 WPF | T00 两系统原生窗口与依赖版本 |
| 实例隔离 | 独立用户数据，共享受管依赖 | T01 / T07 串档、锁与迁移 |
| 安装恢复 | 文件 journal + SQLite 操作记录 | T03 提交边界故障注入 |
| Java 策略 | 元数据要求与组件约束求交 | T04 各平台实际运行时探测 |
| 微软登录 | MDCL public client 与分阶段认证 | T00 / T05 应用配置和真实准入 |
| Mac 旧游戏 | 显式 x64 / Rosetta 兼容配置 | 独立后续组合，不并入原生承诺 |
| 更新 | 首版手动，后续签名自动更新 | T08 发布数据保护；T12 信任与回滚 |

本设计没有要求现在购买服务、申请证书或把秘密发给 Dsh；它把这些外部条件和软件实现的完成状态分别列清楚，便于开发者继续工作和用户验收。
