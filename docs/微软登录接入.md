## 用户登录

在账号页点击「微软登录」，在系统浏览器中使用拥有 Java 版权益的个人微软账号完成授权。MDCL 依次完成授权码 + PKCE、Microsoft 令牌、Xbox Live、XSTS、Minecraft 会话、Java 权益和玩家资料验证。界面显示当前阶段；取消会关闭本次本地等待。

只有全部验证成功才保存账号。刷新令牌在 Windows 使用 DPAPI CurrentUser，在 macOS 使用 Keychain；macOS 的真实 Keychain 与账号登录尚未实测。账号资料 JSON 不包含令牌。退出账号删除对应本地持久凭据。

本地资料和原有实例继续保留，可管理设置与文件。按所有者确认的新发布策略，本地身份不能用于游戏启动；启动核心也拒绝本地、缺令牌、过期或缺玩家资料的会话，没有恢复免认证启动的配置开关。Java 准备完成、进程启动前会再次取得并检查有效会话。

## 维护者覆盖配置

普通用户使用内置 MDCL 应用，无需设置。维护者测试自己的应用时可展开账号页的「微软登录应用设置」，保存自己的 Client ID 后重新打开 MDCL。留空恢复内置应用。配置保存在用户配置目录的 `microsoft-auth.json`：

```json
{
  "schemaVersion": 1,
  "clientId": "自己的应用程序客户端GUID"
}
```

优先级：`MDCL_MICROSOFT_CLIENT_ID` 环境变量 > 用户配置 > MDCL 内置 ID。环境变量保留时，界面保存的值不会覆盖它。更换应用后应重新登录，旧应用的刷新令牌不能作为新应用的凭据使用。不要借用其他启动器的 Client ID，也不要向这个文件加入 secret、令牌或其他字段。

## Minecraft 应用审核

[官方 AppID 审核入口](https://aka.ms/mce-reviewappid)与 Entra 应用注册是两件事。2026-10-25 打开的官方表单明确要求在游戏运行前验证身份及所有权，不接受绕过验证的应用，并说明申请按周审核。已按所有者选择落实启动限制；所有者已核对申请内容并自行完成 EULA / Usage Guidelines 声明与最终提交；浏览器已核实显示“感谢您联系 Mojang Studios”。申请已提交，等待官方审核。本文不代表已经获得批准。

请求类型选择 New AppID for Approval，应用名和 Client ID 使用上表。网站使用公开仓库 `https://github.com/mzxuan08/MountainDogCraftLauncher`；租户 ID 和可与 Azure 信息核对的邮箱由所有者提供，不放入公共示例。

如果 Minecraft 返回 `Invalid app registration`，MDCL 显示 `AUTH_APP_NOT_APPROVED` 并说明需要核对 Client ID 与 API 审核；不会把它解释为“没有购买”，也不会替换成其他应用身份。申请提交后等待官方处理，不反复重复提交。

## 故障定位

| 提示 | 处理 |
| --- | --- |
| `AUTH_CALLBACK_PORT_IN_USE` | 关闭其他 MDCL 登录窗口，释放 34127 后重试 |
| `AUTH_CALLBACK_TIMEOUT` | 浏览器未完成回调；核对个人账号、平台及回调地址，再重试 |
| `AUTH_STATE_MISMATCH` | 本次回调未通过校验，重新发起；不要复制别次登录链接 |
| `AUTH_APP_NOT_APPROVED` | 核对自有 Client ID 与 Minecraft API 申请状态 |
| `AUTH_ENTITLEMENT_MISSING` | 当前账号未通过 Java 版权益检查，使用持有权益的账号 |
| `AUTH_PROFILE_MISSING` | 账号尚无可用 Java 玩家资料，先完成官方资料设置 |
| `AUTH_NO_XBOX_ACCOUNT` | 完成该个人微软账号的 Xbox 资料设置 |
| `AUTH_FAMILY_RESTRICTED` | 根据微软页面处理家庭 / 年龄限制，不绕过限制 |
| `AUTH_REFRESH_EXPIRED` | 授权过期或被撤销，重新登录 |
