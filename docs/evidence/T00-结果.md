## 实际执行

1. `dotnet restore MDCL.sln --locked-mode`：退出码 0，9 个项目还原成功。
2. `dotnet build MDCL.sln -c Release --no-restore`：退出码 0，9 个项目生成成功，0 警告、0 错误。
3. 分别执行 `dotnet publish src/MDCL.Desktop/MDCL.Desktop.csproj -c Release -r <RID> --self-contained true --no-restore -o artifacts/<RID>`：`win-x64`、`osx-arm64`、`osx-x64` 均退出码 0，输出目录相互独立。
4. 直接运行已发布的 `artifacts/win-x64/MDCL.Desktop.exe`：出现 Avalonia 原生桌面窗口，标题 MDCL，中文导航和说明可读，随后通过 Alt+F4 关闭。截图：`T00-windows-window.png`。
