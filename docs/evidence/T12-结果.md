## 已完成

- `UpdateManifest` 固定字段：version、channel、RID、HTTPS 包地址、大小、SHA-256、过期时间、最低启动器版本。
- `UpdateManifestVerifier` 在业务解析前执行 RSA-PSS/SHA-256 验签；签名覆盖规范化 manifest 字节。
- 拒绝：签名错误、过期、通道不符、RID 不符、非 HTTPS 包、非法 SHA-256、未授权降级。
- 更新包下载后再次核对 SHA-256。
- 测试覆盖：有效签名、篡改、过期、错 RID、降级、包摘要错误。

## 替换与回退

- `UpdateInstaller`：验证包摘要 → 安全解压到目标邻接 staging → 检查桌面入口 → 旧目录移入备份 → 新目录原子进入目标；失败恢复旧目录。
- `RollbackAsync`：新目录移出、备份目录恢复，失败时不删除当前目录。
- 独立 `MDCL.Updater` CLI 已加入解决方案，支持 `apply`/`rollback`，状态写入 `mdcl-update-state.json`。
- 测试覆盖：应用新版本、旧版本备份、显式回滚、坏包摘要拒绝且旧目标不变。
