## 已实现

- LaunchPlan：检查 Java 版本/架构、classpath/client 存在；解析 natives、classpath、assets、logging 占位符；内存上限和额外 JVM 参数。
- 账号秘密只在 `GameProcessService` 执行边界绑定；计划本身保留占位符；日志行对已知 token 脱敏。
- 进程使用 `ArgumentList`、`UseShellExecute=false`，参数逐项到达测试子进程；中文、空格、`&`、引号和反斜杠保持完整。
- 启动前移除 `JAVA_TOOL_OPTIONS`、`_JAVA_OPTIONS`、`JDK_JAVA_OPTIONS`、`CLASSPATH`，测试子进程确认未被注入。
- stdout/stderr 双异步读取、有界日志通道、UTF-8 增量解码；4,000 行双流输出不死锁。
- 退出码 0 与非 0 分别记录 Exited/Crashed；`--exit 7` 测试不宣称主菜单。
- 定向 `Kill(entireProcessTree:true)` 和用户停止状态；不扫描其他 Java。
- Java 9+ 超长参数 argfile：引号、反斜杠、空格、拒绝换行；Java 8 超长返回 `PROCESS_COMMAND_TOO_LONG`。
- 敏感日志脱敏器覆盖 Bearer、OAuth code/token、长 JWT/令牌和已知秘密。
- natives 多 jar 合并解压，过滤 META-INF，不保留归档内可执行权限策略之外的文件。

## 未验证/边界

- 进程测试使用 `ArgumentEcho` 小型子进程，不是真实 Minecraft JVM。
- 未实际用 Java argfile 启动 JVM；仅验证写入语法与长度临界决策。
- Windows Job Object 与 macOS 进程组尚未接入，当前依赖 .NET 进程树终止。
- 未达到主菜单检测；只记录进程启动、运行、退出，不把 PID 当主菜单证据。
- 诊断包导出/预览尚未实现；当前只有脱敏与日志组件。
