# T07 结果（Windows 原版闭环）

- 日期：2026-10-25
- 环境：Windows x64，.NET SDK `10.0.402`，Java 17（本机已有 JDK 17），RID `win-x64`
- 运行方式：工作区数据根（测试用 `MDCL_DATA_ROOT`），未使用工作区外的用户数据做破坏性测试。

## 真实操作链路

1. 桌面启动后自动建立本地身份“本地玩家”。
2. 创建实例“我的原版”，版本 `1.20.1`。
3. 点击“安装 / 修复当前实例”，真实访问 Mojang：
   - 官方版本清单与 1.20.1 JSON 校验通过；
   - `client.jar` 23,028,853 字节；
   - 共享库、assets objects、日志配置写入受控共享根；
   - 安装 journal 最终 `Completed`，5 个步骤全部完成；
   - 共享根统计 3,642 个文件、约 701.7 MiB；
   - `resolved-version.json` 与 `instance.json`（revision 2）写入实例目录。
4. 点击“启动”：
   - PID `57156`，Java 17；
   - 首次出现 Mojang 启动画面，随后出现 1.20.1 无障碍欢迎页；
   - 点击 Continue 后到达 Minecraft 1.20.1 主菜单，截图 `T07-windows-main-menu.png`；
   - 使用主菜单 Quit Game 正常退出，Java 进程消失，MDCL 显示“游戏已退出。可再次启动同一实例。”
5. 点击第二次“启动”：
   - 新 PID `53732`，再次到达 1.20.1 主菜单，截图 `T07-windows-second-launch-main-menu.png`。
6. 第三次启动用于退出记录：PID `2052`，会话记录 `T07-session-exit.json` 为 `ExitCode=0`、`state=Exited`、`StoppedByUser=false`。

## 证据

- `T07-windows-main-menu.png`：首次到达 1.20.1 主菜单。
- `T07-windows-second-launch-main-menu.png`：第二次启动到达主菜单。
- `T07-windows-launcher-running.png`：MDCL 启动后的日志与任务状态。
- `T07-windows-exit-state.png`：退出后 MDCL 状态。
