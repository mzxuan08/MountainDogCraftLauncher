## 已实现

- Java 约束求交：下限取最大、上限取最小；无交集或 preferred 越界返回 `JAVA_CONSTRAINT_CONFLICT`。
- 纯规则选择器：探测失败、架构不符、版本过低/过高、缺模块均淘汰并保留原因。
- 显式绑定缺失/不兼容时返回专门错误，不静默改用其他 Java。
- 候选排序：preferred → 受管偏好 → 受管 → 距离 preferred 最近，显式绑定优先且必须兼容。
- `ProcessJavaProbe` 直接参数启动 `java`，不使用 shell；5 秒初始超时，卡死杀进程树；解析 java.version/vendor/os.arch/java.home。
- Windows 发现：JAVA_HOME、PATH、常见 JDK 目录和 JavaSoft 注册表；macOS 发现标准 JVM bundle、用户 bundle、JAVA_HOME/PATH。
- 用户 Java 与受管 Java 分离；探测失败候选仍可见但不参与选择。
- Adoptium Temurin 元数据适配：按 OS/arch/major 获取 JDK、HTTPS 链接和 SHA-256。
- 受管安装：下载 → 安全解压 → 定位 java → 实际探测版本/架构 → 仅成功后移动到 runtimes → 再探测；失败清理 staging，不登记半成品。
- Windows 真实 Java 21 探测成功，`ProcessJavaProbe.TryMajor` 覆盖 1.8/17/21/25。
