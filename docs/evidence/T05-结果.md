## 已实现

- 本地身份：稳定 AccountId，明确 `Local` 类型，空会话令牌，不伪装微软登录。
- 微软授权码 + PKCE S256、随机 state、仅 `127.0.0.1` loopback 回调；系统浏览器打开；5 分钟回调超时；state/取消/缺少 code 分类错误。
- Microsoft OAuth token、Xbox Live、XSTS、Minecraft token、权益、profile 分阶段实现；`expires_in` 管理会话到期。
- XErr 映射为无 Xbox 账号、地区限制、家庭限制等独立错误；权益空与 profile 不存在分别报错。
- refresh token 轮换：新 token 原子替换 vault；同一账号刷新使用 single-flight，并发只发生一次刷新。
- 凭据不可读时直接报错，无明文回退。
- 退出登录删除系统凭据、公开账号记录和内存会话，不结束游戏。
- Windows DPAPI CurrentUser 专用文件：加密往返、磁盘上无明文、删除后读取为 null。
- macOS Keychain 适配使用 Security.framework 直接 API，不经 shell 传递秘密；尚未在 Mac 运行。
- 未配置 MDCL public client ID 时真实登录返回 `AUTH_CLIENT_NOT_CONFIGURED`。
