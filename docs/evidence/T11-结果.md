## 已完成

- `MrpackReader` 安全读取 `.mrpack`：
  - 必须存在根 `modrinth.index.json`；
  - 限制索引大小、只接受 `formatVersion=1`、`game=minecraft`；
  - 读取 Minecraft、Fabric/Forge/NeoForge/Quilt 依赖；
  - 解析文件 SHA-512/SHA-1、大小、HTTPS 下载地址；
  - 拒绝目录穿越、绝对路径、盘符、空段和重复路径；
  - 统计 overrides/client-overrides 文件数与字节数；
  - Quilt 和未知依赖保留 warning，不伪装为完整支持。
- `CreatePlan` 生成带 SHA-512/SHA-1 的 `InstallPlan`，目标为实例 `.minecraft` 相对路径，供现有 coordinator 执行。
- `ArtifactDownloader` 增加 SHA-512。
- 不执行整合包脚本或自带程序。

## 导入流程实现

- `MrpackImportService` 已串联：解析预览 → 创建新实例 → 安装原版或 Fabric → 下载索引文件到实例 `.minecraft` → 合并 overrides/client-overrides。
- `MrpackOverrideExtractor` 使用安全解压器先落 staging，再复制到实例；拒绝覆盖已有用户文件（`MRPACK_OVERRIDE_CONFLICT`），客户端 overrides 后合并。
- `forge` / `neo-forge` 依赖已接入自动导入：先安装原版资源，再调用 `InstallForgeAsync`；Quilt 仍拒绝自动导入。

## 真实 mrpack 导入与启动

构造最小合法 mrpack v1：

- 根 `modrinth.index.json`：`formatVersion=1`、`game=minecraft`、`dependencies.minecraft=1.20.1`、`files=[]`；
- `overrides/options.txt`；
- `overrides/config/mdcl-pack-test.txt`。

通过桌面“整合包”页导入后：

1. 创建实例 `导入的整合包` 并完成 1.20.1 原版安装；
2. overrides 真实写入实例 `.minecraft`，两个文件内容正确；
3. 点击启动，真实进入 `Minecraft 1.20.1` 主菜单。

发现并修复真实 bug：无 loader 的原版 mrpack 中，`dependencies.EnumerateObject().FirstOrDefault(...)` 返回默认 `JsonProperty`，读取 `.Name` 抛 `InvalidOperationException`。修复为可空 `JsonProperty`，并新增原版无 loader 的解析测试。

证据：
- `T11-mrpack-import.png`
- `T11-mrpack-launch.png`
- `T11-mrpack-launch.log`

## Modrinth 适配

- `ModrinthProvider` 已实现无需 API key 的搜索、项目版本筛选（游戏版本 + loader）和单个版本详情。
- 解析项目公开字段、版本类型、loader/游戏版本数组，以及文件 HTTPS 地址、大小、SHA-512/SHA-1、primary 标记。
- 非成功 HTTP 返回结构化 `MODRINTH_HTTP`；非 HTTPS 文件地址拒绝。
- 测试覆盖搜索解析、过滤 URL、文件摘要和 HTTP 失败。
- `ModrinthInstallService` 选择 primary 文件（无 primary 时取第一个），优先 SHA-512、回退 SHA-1；获取实例租约后写入实例 `mods/<filename>`；拒绝不安全文件名、缺摘要、已存在目标文件和运行中实例修改。
- `ModrinthInstallService` 有受控下载器测试，验证目标路径、摘要算法和冲突保护。
- 桌面新增“Modrinth 模组”区：搜索、结果列表、按当前实例游戏版本/加载器选择 release 版本并安装。
- 已真实网络验收搜索：查询 `sodium` 返回 20 个项目，首项 Sodium 253,905,607 下载；截图 `T11-modrinth-search.png`。
- 已真实网络验收安装：在 Fabric 0.16.14 测试实例中选择 Sodium，成功写入
  `sodium-fabric-0.5.13+mc1.20.1.jar`，971,552 字节，SHA-512
  `81c64f9c2d3402dfa43ee54d8f5a054f5243bfb08984e3addcab9fe885073c79c43c1c8c41e8f30b625d26a656f82a8e5f370bbbbf222ff1c08f4b324edb7ea4`；
  截图 `T11-modrinth-install.png`。
