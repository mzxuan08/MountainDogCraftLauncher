# T13 桌面界面重构结果

- 日期：2026-10-25

## 问题

- 左侧实例栏把安装、Fabric、Forge/NeoForge、启动/停止全部堆在底部，窗口内被挤出或对比度过低，几乎不可见。
- 右侧所有功能堆成一个长页面，模组、整合包、账号、日志需要长距离滚动才能看到。
- 禁用态按钮被主题压到接近全黑，即使存在也像“消失了”。

## 改动

- 左侧固定为实例列表 + 独立“实例操作”卡片，安装/启动/停止始终可见。
- 右侧改为六个标签页：概览、加载器、模组、整合包、账号、日志。
- 加载器安装从侧栏移到“加载器”页；模组、整合包、账号各自独立成页。
- 统一按钮、输入框、卡片、标签页样式；增加 primary/danger/dark 和可读的禁用态。
- 安装/启动/停止保持可点击；缺少实例或账号时在状态栏给出明确提示，而不是显示几乎不可见的禁用按钮。
- 实例列表去除名称重复，详情行显示版本、加载器和安装状态。

## 验证

- `dotnet test MDCL.sln -c Release --no-restore`：119 项通过。
- 当前 Windows 包实际启动检查：实例栏、操作卡片、标签页和模组页布局均完整可见。
- 截图：`T13-ui-redesign.png`。
