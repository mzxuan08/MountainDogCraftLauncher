# T13 桌面界面重构结果

- 日期：2026-10-25

## 问题

- 左侧实例栏把安装、Fabric、Forge/NeoForge、启动/停止全部堆在底部，窗口内被挤出或对比度过低，几乎不可见。
- 右侧所有功能堆成一个长页面，模组、整合包、账号、日志需要长距离滚动才能看到。
- 禁用态按钮被主题压到接近全黑，即使存在也像“消失了”。

## 改动

- 左侧固定为实例列表 + 独立“实例操作”卡片，安装/启动/停止始终可见。
- 右侧改为六个标签页：概览、加载器、模组、整合包、账号、日志。
- 加载器安装从侧栏移到“加载器”页；模组、整合包、账号各自独立成页。
- 统一按钮、输入框、卡片、标签页样式；增加 primary/danger/dark 和可读的禁用态。
- 安装/启动/停止保持可点击；缺少实例或账号时在状态栏给出明确提示，而不是显示几乎不可见的禁用按钮。
- 实例列表去除名称重复，详情行显示版本、加载器和安装状态。

## PCL 风格二次重构

- 顶部改为深色渐变启动栏，状态提示与刷新集中到标题区。
- 左侧实例栏加入版本图标、名称/版本/加载器三级信息、选中高亮和固定底部启动卡片。
- 主页增加渐变主视觉区：实例名、版本/加载器/安装状态标签、开始游戏与安装按钮。
- 增加三列状态卡（游戏版本、加载器、运行状态）和“新建实例 / 当前任务”布局。
- 增加四个功能入口卡（加载器、模组、整合包、账号），点击直接切换标签页。
- 标签页改为胶囊式选中态，默认固定在“主页”，不再启动时落到日志页。
- 统一圆角、阴影、文本层级、配色，减少整页空白。

## 验证

- `dotnet test MDCL.sln -c Release --no-restore`：128 项通过。
- 当前 Windows 包实际启动检查：主页、实例列表、功能入口和“管理模组”跳转均正常。
