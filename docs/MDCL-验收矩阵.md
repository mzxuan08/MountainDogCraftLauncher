# MDCL 验收矩阵

以下为原始验收目标，保留其通过条件。2026-10-25 已实现 T00—T12 代码并执行分层验证；当前结果见 [接续记录](evidence/continuation-final.md)、[发布矩阵](evidence/release-matrix.md) 和 [逐项状态](evidence/acceptance-status.csv)。未做的组合不得从“框架支持”推断为通过。

用例证据分为“纯规则测试”“故障注入 / 集成测试”“真机交互”“正式分发验证”。同一项可能需要多种证据。


2026-10-25 产品规则更新：用户确认正式版仅允许已验证正版微软账号启动，保留本地资料和实例数据。原 U06 本地身份启动目标被此规则取代；旧原版/加载器主菜单截图属于历史本地会话证据，不能作为 alpha.3 微软认证后启动通过。当前外部 AppID 审核与真实账号验收待完成。

## 平台与游戏组合

| 发布目标 | 系统基线 | 原版固定回归样本 | 运行时要求 | 实测要求 |
| --- | --- | --- | --- | --- |
| win-x64 | Windows 11 24H2+ 受支持版本 | 1.20.1、26.3 | 依各自元数据及兼容要求选择 x64 Java | 干净用户环境、主菜单、退出、二次启动 |
| osx-arm64 | macOS 15+ 受支持版本，Apple Silicon | 1.20.1、26.3 | arm64 Java 与 arm64 natives | 原生运行，不借 Rosetta 冒充 |
| osx-x64 | macOS 15+ 受支持版本，Intel | 1.20.1、26.3 | x64 Java 与 x64 natives | Intel 真机；Rosetta 结果另列 |
| Apple Silicon 旧游戏兼容 | 单独的后续测试组 | 1.16.5 等按需要冻结 | x64 Java、x64 natives、Rosetta，另核对加载器 | 不计入首版现代原版保证 |

固定样本用于回归；“安装最新正式版”另外在线验证。26.3 / Java 25 来自设计当日官方元数据，今后按元数据更新，不硬编码最新版。

## 下载、安装与安全边界

| ID | 场景 | 通过条件 |
| --- | --- | --- |
| D01 | 官方完整安装与缓存命中 | 摘要正确，缓存命中有来源记录 |

| D03 | Range 返回 200 而非 206 | 临时文件从零重建，无追加污染 |
| D04 | Range 返回 416 或 ETag 改变 | 验证或重建残片，不使用不明身份数据 |

| D08 | 缓存与游戏库跨磁盘 | 目标邻接临时文件校验后提交，无半文件 |
| D09 | 磁盘满、只读目录、文件被占用 | 保留旧实例，给出可操作错误，不无限重试 |
| D10 | 总量未知、高速小文件、多任务 | 未知量不显示假百分比；事件有序，UI 限流 |
| S03 | ../、绝对路径、UNC、ADS、链接、重名归档 | 拒绝越界和歧义写入，不覆盖目标根外文件 |
| S04 | 归档炸弹、父路径重解析点、可执行权限 | 限制数量与体积；安全提取；仅恢复受管运行时必要权限 |
| S05 | Keychain 拒绝 / 锁定、DPAPI 无法解密 | 报凭据不可访问；无明文降级 |
| S06 | 日志、异常、URL、启动预览含 token | 落盘前脱敏，诊断包中无秘密 |
| S07 | 浏览器回调、跨域重定向、私有响应缓存 | state / PKCE 校验；秘密不跨域传播或进入公共缓存 |
| S08 | 恶意 JVM / 脚本字段、敏感 argfile 遗留 | 首版不自动执行脚本；受限临时文件可清理 |
